Trust should be easy to check.

Every certificate has a unique identity. Scan its QR code to check whether it is valid, revoked, or doesn't exist.

QR opens a DNS error on some networks?

This is a network DNS issue, not a certificate-data issue. The public verification service is hosted online and can be checked directly from the public app URL.

  1. On Windows, open Network settings → DNS settings.
  2. Temporarily use 1.1.1.1 as Preferred DNS and 8.8.8.8 as Alternate DNS.
  3. Run ipconfig /flushdns in PowerShell.
  4. Refresh the verification page and scan the QR code again.

This is only a troubleshooting step for networks whose DNS resolver cannot resolve the public Railway domain.
