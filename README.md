# CertiVerify Showcase

A standalone landing page for the CertiVerify certificate-generation and verification web app.

## Run

No build step is required.

Open `index.html` directly, or use VS Code Live Server.

The **Launch App** buttons currently point to:
`http://localhost:5173`

Change that URL to the deployed CertiVerify app when the app is ready.
